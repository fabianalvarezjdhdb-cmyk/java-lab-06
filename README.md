# Laboratorio 6 — Arquitectura Java: de la ejecución del programa a la memoria

Repositorio correspondiente al desarrollo del Laboratorio 6 del programa de formación, enfocado en la arquitectura de Java 21, compilación, bytecode, manejo de memoria (Stack y Heap), paso de parámetros por valor y casos de estudio.

## Contenido del Laboratorio
- **Práctica 6.1:** JDK, JRE y JVM (Verificación de herramientas con `java`, `javac` y `javap`).
- **Práctica 6.2:** Compilación, bytecode y ciclo de ejecución.
- **Práctica 6.3:** Stack (Pila): llamadas a métodos, parámetros y variables locales.
- **Práctica 6.4:** Heap: objetos, arreglos, identidad y referencias.
- **Práctica 6.5:** Paso de parámetros y caso real de PetMatch (`MemoryDemo.java`).
- **Reto Integrador (`memory-challenge`):** Seguimiento de perfiles de mascotas (`PetProfile.java` y `MemoryChallenge.java`).
